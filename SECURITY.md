# Security Policy

This repository is a static GitHub Pages site. It must not contain credentials, API keys, authentication tokens, private datasets, analytics identifiers or server-side secrets.

## Reporting

For a security vulnerability, use GitHub's private vulnerability reporting flow if enabled. Do not disclose exploitable issues publicly before they are fixed.

For ordinary data-quality errors, model-version corrections or broken links, use a public issue or pull request.

## Supply chain

Chart.js is loaded from a version-pinned jsDelivr URL. New runtime dependencies should be justified and version-pinned. GitHub Actions should use maintained official actions.
